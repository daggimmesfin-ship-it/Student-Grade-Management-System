# Student Grade Management System

## About
A Python console application for managing student records and academic performance.

## Features
- Register students and enter their scores
- Validate student information and scores
- Calculate average scores and grades
- Search for students by ID
- Display the top-performing student
- Save and load student data using JSON

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

   `py main.py`
